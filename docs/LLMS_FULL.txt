# Valix Complete API & Context Reference for LLM Prompting

> This file contains the complete, unabridged technical reference of Valix v1.0.5 for ingestion into Large Language Models (LLMs) such as Claude, GPT-4, Gemini, and Cursor/Antigravity coding assistants.

---

## 1. Executive Summary & Core Rules

- **Library Group**: `com.developersyndicate.valix`
- **Current Version**: `1.0.5`
- **Primary Paradigm**: KSP-generated procedural Kotlin validation (Zero Reflection).
- **Execution Target**: Kotlin Multiplatform (`commonMain`, JVM, Android, iOS, Web/JS, WebAssembly/Wasm).
- **Codegen Rule**: Any class containing constraint annotations or `@Valid` triggers KSP generation of `<ClassName>Validator` inside `<packageName>.generated`.
- **Primary Method Signature**:
  `validate(value: T, vararg groups: KClass<*>, failFast: Boolean = false): ValidationResult`
  `suspend validateAsync(value: T, vararg groups: KClass<*>, failFast: Boolean = false): ValidationResult`

## 3. Exhaustive Annotation Catalogue

### String Constraints (`io.valix.annotations.*`)
- `@NotNull(message = "", messageKey = "", groups = [])`: Value must not be `null`.
- `@NotBlank(message = "", messageKey = "", groups = [])`: String must contain non-whitespace characters.
- `@NotEmpty(message = "", messageKey = "", groups = [])`: String length > 0.
- `@Email(message = "", messageKey = "", groups = [])`: RFC-compliant email string.
- `@MinLength(value: Int, message = "", messageKey = "", groups = [])`: Minimum string length.
- `@MaxLength(value: Int, message = "", messageKey = "", groups = [])`: Maximum string length.
- `@Pattern(regex: String, message = "", messageKey = "", groups = [])`: Regex match.
- `@Url(message = "", messageKey = "", groups = [])`: Valid URL format.
- `@PhoneNumber(message = "", messageKey = "", groups = [])`: E.164 phone format.
- `@Alpha(message = "", messageKey = "", groups = [])`: Letters only.
- `@AlphaNumeric(message = "", messageKey = "", groups = [])`: Letters and digits only.
- `@LowerCase(message = "", messageKey = "", groups = [])`: All lowercase.
- `@UpperCase(message = "", messageKey = "", groups = [])`: All uppercase.
- `@Contains(value: String, message = "", messageKey = "", groups = [])`: Must contain substring.
- `@StartsWith(value: String, message = "", messageKey = "", groups = [])`: Must start with prefix.
- `@EndsWith(value: String, message = "", messageKey = "", groups = [])`: Must end with suffix.

### Numeric Constraints (`Int`, `Long`, `Float`, `Double`, `Short`, `Byte`)
- `@Min(value: Long, message = "", messageKey = "", groups = [])`: Value >= min.
- `@Max(value: Long, message = "", messageKey = "", groups = [])`: Value <= max.
- `@Range(min: Long, max: Long, message = "", messageKey = "", groups = [])`: Min <= Value <= Max.
- `@Positive(message = "", messageKey = "", groups = [])`: Value > 0.
- `@PositiveOrZero(message = "", messageKey = "", groups = [])`: Value >= 0.
- `@Negative(message = "", messageKey = "", groups = [])`: Value < 0.
- `@NegativeOrZero(message = "", messageKey = "", groups = [])`: Value <= 0.

### Collection & Enum Constraints
- `@NotEmpty(message = "", messageKey = "", groups = [])`: Collection size > 0.
- `@Size(min: Int, max: Int, message = "", messageKey = "", groups = [])`: Collection size in range.
- `@AllowedValues(value: Array<String>, message = "", messageKey = "", groups = [])`: Must match set.

### Date & Time Constraints
- `@Past`: Date/time strictly before current moment.
- `@PastOrPresent`: Date/time before or equal to current moment.
- `@Future`: Date/time strictly after current moment.
- `@FutureOrPresent`: Date/time after or equal to current moment.

### Security, Conditional & Nested Control
- `@Sensitive(mask: String = "********")`: Redacts `rejectedValue` in generated `ValidationError`.
- `@ValidateIf(field: String, equals: String = "")`: Evaluates constraints only if target sibling property matches condition.
- `@Valid`: Recursively validates nested objects or collection items.
- `@FieldsMatch(first: String, second: String, message: String = "")`: Class-level check for matching fields.

## 4. Custom Validator Interfaces

### Property-Level Sync Validator
```kotlin
class ZipCodeValidator : ConstraintValidator<String> {
    override fun validate(value: String, context: ValidationContext): Boolean {
        return value.matches(Regex("^\\d{5}(-\\d{4})?$"))
    }
}
```

### Property-Level Suspending / Async Validator
```kotlin
class UniqueUsernameValidator : AsyncConstraintValidator<String> {
    override suspend fun validate(value: String, context: ValidationContext): Boolean {
        return userRepository.existsByUsername(value).not()
    }
}
```

### Class-Level Multi-Field Validator
```kotlin
class DateRangeValidator : ObjectConstraintValidator<Event> {
    override fun validate(value: Event, context: ValidationContext): Boolean {
        return value.endDate.isAfter(value.startDate)
    }
}
```

## 6. Complete Framework Code Examples

### Spring Boot
```kotlin
@RestController
@RequestMapping("/api/users")
class UserController {
    @PostMapping
    fun createUser(@ValidValix @RequestBody request: CreateUserRequest): ResponseEntity<UserResponse> {
        return ResponseEntity.ok(userService.create(request))
    }
}
```

### Ktor
```kotlin
install(ValixKtorPlugin) {
    onValidationError { call, errors ->
        call.respond(HttpStatusCode.BadRequest, mapOf("errors" to errors))
    }
}
```

### Jetpack Compose
```kotlin
val formState = rememberValixForm(initialValue = RegisterForm("", ""))
OutlinedTextField(
    value = formState.value.email,
    onValueChange = { email -> formState.update { copy(email = email) } },
    isError = formState.hasFieldError("email")
)
```
